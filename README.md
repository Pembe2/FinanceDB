# Retirement Toolkit (Modular Static Site)

This is the modular, multi-file version of your Retirement Toolkit.

## Run locally (required for ES module imports)

From the project root:

### Option A: Python
```bash
python -m http.server 8080
```
Then open:
- http://localhost:8080

### Option B: VS Code
Use the **Live Server** extension and open `index.html`.

## Deploy
This is a static site. You can deploy to GitHub Pages by pushing this folder to a repo and enabling Pages on the `main` branch.
